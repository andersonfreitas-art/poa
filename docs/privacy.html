Política de Privacidade

POA - Professor Online Automático

Última atualização: 20 de novembro de 2025

Esta Política de Privacidade descreve como a extensão POA - Professor Online Automático, desenvolvida por Anderson Freitas ("o Desenvolvedor"), acessa, utiliza e protege as informações do usuário.

A transparência é nosso pilar principal. O POA foi desenvolvido para aumentar a produtividade de professores da rede estadual do Ceará, operando com total respeito à privacidade dos dados de alunos e docentes.

1. Coleta e Armazenamento de Dados

A extensão POA não coleta, armazena, transmite ou vende quaisquer dados pessoais de alunos ou professores para servidores externos.

  • Processamento Local: Todo o processamento de dados (notas, frequência e relatórios) ocorre localmente no navegador do usuário (client-side). Nenhum dado inserido na extensão é enviado para o Desenvolvedor ou para terceiros.
  • Ausência de Banco de Dados: A extensão não possui banco de dados próprio. Ela atua apenas como um facilitador de interface entre a área de transferência do usuário e os formulários do sistema oficial.

2. Uso de Permissões e Acesso a Sites

Para funcionar corretamente, a extensão solicita as seguintes permissões, estritamente para os fins descritos:

  • Acesso aos domínios da SEDUC (*.seduc.ce.gov.br): A extensão interage com páginas oficiais da Secretaria da Educação (como Portal do Professor, SIGE, etc.) para identificar a página ativa (feedback visual) e preencher formulários mediante comando explícito do usuário.
  • Side Panel (Painel Lateral): Utilizado para oferecer uma interface de controle persistente onde o usuário insere dados temporários para automação e acessa links rápidos.

3. Dados Sensíveis e Educacionais

A extensão manipula dados educacionais (como matrículas e notas) apenas de forma transitória:

  1. O usuário copia os dados de sua planilha pessoal.
  2. O usuário cola os dados no Painel Lateral da extensão.
  3. A extensão injeta esses dados nos campos correspondentes do site oficial da SEDUC-CE.
  4. Após o fechamento do navegador ou recarregamento da extensão, os dados inseridos no Painel são descartados.

A responsabilidade pela veracidade e conferência dos dados inseridos no sistema oficial é inteiramente do usuário (professor/gestor). Recomenda-se sempre conferir os dados antes de salvar no sistema oficial.

4. Login e Credenciais

A extensão não tem acesso às suas senhas. O funcionamento depende de o usuário já estar autenticado no sistema do Portal do Professor por meios próprios. A extensão não interfere, salva ou manipula o processo de login.

5. Isenção de Vínculo Institucional

O POA - Professor Online Automático é uma ferramenta independente, desenvolvida para fins de produtividade.

  • Não Oficial: Esta extensão não é um produto oficial da Secretaria da Educação do Estado do Ceará (SEDUC-CE) ou do Governo do Estado do Ceará.
  • O uso da ferramenta é facultativo e de total responsabilidade do usuário.

6. Alterações nesta Política

Reservamo-nos o direito de atualizar esta Política de Privacidade para refletir mudanças na legislação ou melhorias na funcionalidade da extensão. As alterações entrarão em vigor imediatamente após a publicação da nova versão na Chrome Web Store.
